## 九、互文偏好：顾祖禹引什么·不引什么（方案 4.2(5)）

方法：以注文字数为郦道元注意力、以《读史方舆纪要》引文语境并提次数为顾祖禹引用量，取前四十水作 Spearman 位次相关。

- **ρ = 0.37（弱正相关）**——顾祖禹对《水经注》的引用与郦道元的笔墨分配显著错位
- 顾引高而郦注少：**易水、汾水、洛水、涑水、清水、湘水、漳水、颍水**——边关要河（易水紫荆、漳水邺都）与漕运孔道
- 郦注多而顾引少：**汝水、浊漳水、淮水、渭水、漯水、睢水、渐江水、存水**——巨川自然史与南国游览之笔
- 两榜同名（七水）：江、沔、河、泗、济、渠、谷——兼具军事要冲与文本密度者两全

> 千年之后的史家按兵要剪裁千年之前的注家：ρ=0.37 即这道剪裁的量化痕迹。
